
# 🎨 Card Making & Form Project

> 🚀 A responsive and interactive web project built using **HTML**, **CSS**, and **JavaScript**.

## 📖 Overview

This project demonstrates the creation of stylish **cards** 🃏 and an interactive **form** 📝 with client-side validation. It focuses on building a modern, responsive, and user-friendly interface while practising core front-end development concepts.

## ✨ Features

* 🃏 Responsive Card Design
* 🎨 Modern & Clean UI
* 📱 Mobile-Friendly Layout
* 📝 Interactive Contact Form
* ⚡ JavaScript Form Validation
* 🚨 Error & Success Messages
* 🖱️ Smooth Hover Effects
* 💻 Well-Organized Code Structure

## 🛠️ Technologies Used

* 🌐 **HTML5**
* 🎨 **CSS3**
* ⚡ **JavaScript (ES6)**

## 📂 Project Structure

```text
📁 Card-Making-Form
│── 📄 index.html

```

## 🎯 Learning Objectives

* 📌 Build responsive card layouts.
* 🎨 Improve UI design with CSS.
* ⚡ Add interactivity using JavaScript.
* 📝 Validate user input effectively.
* 💡 Write clean and maintainable front-end code.

1. 📥 Clone or download this repository.
2. 📂 Open the project folder.
3. 🌐 Launch `index.html` in your browser.
4. 🎉 Explore the cards and test the interactive form.
